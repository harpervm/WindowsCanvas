# WindowsCanvas

**Transform your desktop into an infinite scrollable canvas where windows live in a virtual world space.**

## What is WindowsCanvas?

WindowsCanvas creates a virtual desktop workspace that extends far beyond your physical screen. Instead of being confined to a single monitor, your application windows exist in a large virtual coordinate space (3x3 grid by default). You can pan and scroll through this space to view different windows, just like navigating a canvas.

### Key Features

- **Virtual World Space**: Windows are positioned in a large virtual coordinate system (7680×4320 pixels by default)
- **Camera Viewport**: Your screen acts as a viewport into this virtual space - pan around to see different areas
- **Smooth Navigation**: Hold middle mouse button and drag to pan the camera view
- **Minimap Overlay**: A real-time minimap in the bottom-right corner shows your entire workspace with all windows and your current viewport
- **Persistent Window Positions**: Windows maintain their positions in world space as you navigate, creating a spatial organization system

### How It Works

1. All application windows are mapped to coordinates in a virtual world space
2. Your physical screen shows a "camera view" of a portion of this world (one screen-sized area)
3. When you pan the camera, windows are repositioned on-screen based on their world coordinates
4. The minimap provides an overview of the entire workspace, helping you navigate and locate windows

### Use Cases

- **Multi-Monitor Workflow**: Organize windows across a virtual multi-monitor setup
- **Project Organization**: Group related windows in different areas of the canvas
- **Power User Desktop**: Create a spatial organization system for your applications
- **Presentation Mode**: Arrange windows in a specific layout for demos or workflows
